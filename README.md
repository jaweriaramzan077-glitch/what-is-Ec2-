# ☁️ Amazon EC2

**EC2 (Elastic Compute Cloud)** AWS ki ek cloud service hai jo humein **virtual servers** provide karti hai.

Hum EC2 ki help se cloud mein ek virtual server create karke us par **websites, applications aur software** run kar sakte hain.

### Why Do We Need EC2?

EC2 ki zaroorat is liye hoti hai kyun ke humein physical server khareedne aur maintain karne ki zaroorat nahi hoti. Hum AWS par apni requirement ke according virtual server create kar sakte hain.

### Simple Example

Agar humein ek website host karni hai, to hum **EC2 instance** create karke us par web server install kar sakte hain.

**Easy Meaning:**
**EC2 = AWS ka Virtual Server**

### Key Points

* EC2 cloud mein virtual server provide karta hai.
* Is par applications aur websites run ki ja sakti hain.
* Resources ko requirement ke according choose kiya ja sakta hai.
* Physical server maintain karne ki zaroorat kam ho jati hai.
